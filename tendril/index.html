A zero-dependency physics engine combining Ricardo Mendieta's SVG gooey ink dynamics and text-inverting lens with Motion Bench's frame-rate independent kinematics. Features 1:1 natural pointer tracking, multi-checkpoint waypoint weaving, phone touch trails, and severed falling ropes.

⚓ 2-Stage Triple-Tap Anchor & Falling Physics Rope:

Triple-click anywhere to pin the tail at that spot. Stretch the cord across the page, then triple-click again to sever the cord into an independent falling rope!

1️⃣ Stage 1: Drop Anchor (1st Triple-Tap) Triple-Click anywhere on screen to pin the tail at that spot. A circular anchor appears with a fluid burst.
2️⃣ Stage 2: Stretch & Sag Physics Move your cursor away to stretch the liquid cord. The tendon naturally thins down (Poisson's effect) and droops with gravitational sag.
3️⃣ Stage 3: Sever & Drop (2nd Triple-Tap) Triple-Click again anywhere to sever the stretched cord. It detaches completely from your cursor and tumbles down the screen under Verlet gravity!
📱 Mobile & Phone Touch: Touch & drag your finger across the screen to draw the liquid rope trail; tap anywhere to trigger pressurized liquid splashes and gravitational spills!

Configuration Options Reference

Complete options table supported by the Tendril constructor

Option / Method Type Default Description
color String '#10b981' Primary cursor head and rope color (Emerald Green default).
secondaryColor String '#06b6d4' Secondary tail gradient color (Cyan default).
mixBlendMode String 'difference' Blend mode: 'difference' (Mendieta text-reveal lens), 'normal', 'screen'.
multiCheckpoints Boolean true Allows planting multiple sequential stop checkpoints across the screen.
tripleTapAnchor Boolean true Triple-tap to enter checkpoint mode and release all into severed falling rope.
preventTextSelectOnTap Boolean true Automatically blocks accidental word/paragraph text selection on rapid taps.
severedRopeGravity Number 0.42 Downward gravitational acceleration for detached ropes.
spillOnClick Boolean true Pressurized liquid erupts and cascades down on pointer clicks or touch taps.
spillCount Number 14 Number of liquid drops spawned per spill.
addCheckpoint(x, y) Method — Plants a new checkpoint pin at coordinates (or cursor position).
releaseAllAndDrop() Method — Detaches rope from all checkpoints and severs it into Verlet falling gravity.
setBlendMode(mode) Method — Dynamically changes cursor blend mode ('difference' | 'normal' | 'screen').
reportBug(note) Method — Opens email client addressed to mauryanishant2005@gmail.com with attached diagnostics.
