🔍 Why Did Higher Blur Cause Less Spill?

The SVG gooey filter blurs elements with feGaussianBlur stdDeviation="σ" and then applies a high-contrast alpha cutoff feColorMatrix alpha = blur*34 - 14. When blur is high, small droplets get diluted over a wider radius, dropping their peak alpha below the 14/34 (41%) threshold. The filter treats them as empty space and completely erases them!

⚡ The Solution: Adaptive Droplet Mass

Tendril now uses Adaptive Droplet Mass Compensation. When you raise gooeyBlur, drop radii automatically scale proportionally so each droplet maintains sufficient pixel density to cross the alpha threshold. Even at high blur, spills remain full, thick, and viscous!

Dedicated Spill API Example 
// 1. Initialize Tendril
const cursor = new Tendril({
  color: '#ee3d3d',
  spillOnClick: true
});

// 2. Call spill() separately anywhere programmatically:
cursor.spill(); // spills at current cursor location

// Or with custom coordinates & volume:
cursor.spill({
  x: 400,
  y: 300,
  count: 25,     // 25 drops
  speed: 6.5,    // launch velocity
  gravity: 0.45  // falling gravity
});
